Link your deck tracker

Sign in (top menu) to create your key.

The tracker on your PC uses this key to save your matches to your account. Create it, then paste it into a file called tracker_key.txt in the tracker's folder.

The key works like a password for your matches on this site (not your Google account): keep it private and never share it or put it on GitHub.

Get the tracker (Windows)

  1. Install Python from python.org (tick "Add python.exe to PATH" during the install).
  2. Download the tracker: on github.com/Brainiac1830/showdown-tracker click Code > Download ZIP, and unzip it anywhere.
  3. Open a terminal in that folder and run: python -m pip install playwright pillow
  4. Create your key above and save it as tracker_key.txt in that folder.
  5. Run python tracker.py. A browser window opens on Showdown: log in there and play. Your matches appear on this site, and the players you meet are shared with everyone (Players page).

What's shared with other players

Your match history is private: only you can see it.

What you saw other players play (their name, classes, and the cards they played in that match) is shared, so everyone gets better "likely cards" on the Players page and in the overlay. Your own deck is never shared by your tracker.
